### 3. Instrument your application

Export directly to Oodle using the HTTPS OTLP endpoint shown in your Oodle tile and both authentication headers. Replace `OODLE_ENDPOINT`, `API_KEY`, and `INSTANCE_ID` below with your own values; keep credentials private. Use the base endpoint without `/v1/traces` or `/v1/metrics`: the exporters append the signal paths.

These examples use OTLP/HTTP with protobuf. Set the protocol before starting your Python application:

```shell
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
```

If you use the optional Collector from step 2, use the Collector examples instead.

    <Tabs>
      <Tab title="SDK">
        **Send directly to Oodle:**

        ```python
        import openlit

        openlit.init(
            service_name="my-ai-service",
            otlp_endpoint="https://OODLE_ENDPOINT",
            otlp_headers={
                "X-API-KEY": "API_KEY",
                "X-OODLE-INSTANCE": "INSTANCE_ID",
            },
        )
        ```

        **Or send through your OpenTelemetry Collector:**

        <Tabs>
          <Tab title="Function Arguments">
          ```python
          import openlit

          openlit.init(
            otlp_endpoint="YOUR_OTELCOL_URL:4318"
          )
          ```

          Replace:
          1. `YOUR_OTELCOL_URL:4318` with your OpenTelemetry Collector HTTP endpoint.
             * Example (Local): `http://127.0.0.1:4318`
             * Example (Remote): `http://otel-collector.company.com:4318`
          </Tab>
          
          <Tab title="Environment Variables">
          ```python
          import openlit

          openlit.init()
          ```

          Set these environment variables:
          ```shell
          export OTEL_EXPORTER_OTLP_ENDPOINT="YOUR_OTELCOL_URL:4318"
          export OTEL_SERVICE_NAME="my-ai-service"
          export OTEL_DEPLOYMENT_ENVIRONMENT="production"
          ```

          Replace:
          1. `YOUR_OTELCOL_URL:4318` with your OpenTelemetry Collector HTTP endpoint.
             * Example (Local): `http://127.0.0.1:4318`
             * Example (Remote): `http://otel-collector.company.com:4318`
          </Tab>
        </Tabs>

        Refer to the OpenLIT [Python SDK repository](https://github.com/openlit/openlit/tree/main/sdk/python) for more advanced configurations and use cases.
      </Tab>
      
      <Tab title="CLI">
        **Send directly to Oodle without changing application code:**

        ```shell
        openlit-instrument \
          --service_name "my-ai-service" \
          --otlp_endpoint "https://OODLE_ENDPOINT" \
          --otlp_headers '{"X-API-KEY":"API_KEY","X-OODLE-INSTANCE":"INSTANCE_ID"}' \
          python app.py
        ```

        `--otlp_headers` takes a JSON object. Existing environment variables take precedence over CLI arguments.

        **Or send through your OpenTelemetry Collector:**

        <Tabs>
          <Tab title="CLI Arguments">
          ```shell
          # Using CLI arguments
          openlit-instrument \
            --otlp_endpoint "YOUR_OTELCOL_URL:4318" \

            --environment "production" \
            python app.py
          ```
          
          Replace:
          1. `YOUR_OTELCOL_URL:4318` with your OpenTelemetry Collector HTTP endpoint.
             * Example (Local): `http://127.0.0.1:4318`
             * Example (Remote): `http://otel-collector.company.com:4318`
          </Tab>

          ```shell
          # Set environment variables (takes precedence over CLI args)

          export OTEL_SERVICE_NAME="my-ai-service"
          export OTEL_DEPLOYMENT_ENVIRONMENT="production"
          
          # Run your application
          openlit-instrument python app.py
          ```
          
          Replace:
          1. `YOUR_OTELCOL_URL:4318` with your OpenTelemetry Collector HTTP endpoint.
             * Example (Local): `http://127.0.0.1:4318`
             * Example (Remote): `http://otel-collector.company.com:4318`
