---
title: 'List Enrich providers'
openapi: 'GET /api/scanners/{id}/enrich/providers'
---

Return the LLM providers Trustabl Enrich supports, the Vault key name each one needs, and whether Vault holds that key. Key values are never returned.

See [Scanner connectors](/latest/openlit/connectors/scanner#enrich-a-finding) for setup.
